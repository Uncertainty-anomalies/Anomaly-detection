# Распознавание аномальных данных и неизвестных объектов с помощью нейронных сетей

Учебный групповой проект по обнаружению аномалий в текстовых данных и изображениях.

## Цель проекта

Создать единый продукт для поиска аномалий в текстовых данных и изображениях, объединяющий четыре нейросетевые модели для разных прикладных задач.

## Направления работы

### Модель 1. Анализ отзывов и оценок клиентов

Поиск несоответствий между текстовыми отзывами и оценками клиентов при расчёте NPS/CSAT.

**Ответственная:** Хачатрян Виктория Седраковна.

### Модель 2. Обнаружение неизвестных объектов на дороге

Обнаружение неизвестных объектов на дороге для обеспечения безопасности пешеходов и водителей.

**Ответственный:** Абдуллаев Артур Дамирович.

### Модель 3. Роботизированное восприятие (Robotic perception)

Детекция неизвестных предметов на складских объектах.

**Ответственный:** Казаков Максимилиан Эдуардович.

### Модель 4. Мониторинг по спутниковым снимкам

Мониторинг аномальных явлений на основе спутниковых снимков с использованием методов обнаружения объектов вне обучающего распределения (Out-of-Distribution, OOD).

**Ответственная:** Семёнова Виктория Александровна.

## План работы

1. **Поиск и сбор датасетов.** Подбор данных для каждого направления проекта.
2. **Анализ и обработка данных.** Подготовка данных к обучению моделей.
3. **Обучение и валидация DL-моделей.** Оценка качества на основе выбранных метрик.
4. **Подбор гиперпараметров.** Улучшение качества DL-моделей.
5. **Создание единого сервиса.** Объединение моделей для анализа текстовых данных и изображений.
6. **Доработка моделей.** Улучшение и усложнение моделей с учётом комментариев, полученных на промежуточной защите проекта.
7. **Подготовка к итоговой защите.**

### Опциональный этап

Тестирование устойчивости моделей к искусственно созданным атакам и аномально редким кейсам, сгенерированным вручную.
